# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities.

Instead, report it privately via [GitHub Security Advisories](https://github.com/tom-jm69/promhis/security/advisories/new) for this repository. Include:

- A description of the vulnerability and its impact
- Steps to reproduce (a minimal webhook payload, config, or request is ideal)
- Affected version/commit

You should get an initial response within a few days. If confirmed, a fix will be prepared and a security advisory published alongside the patched release.

## Supported Versions

This project ships a single rolling `main` branch and `latest`/versioned images on GHCR. Only the latest release is supported — please upgrade before reporting an issue if you're on an older build.
